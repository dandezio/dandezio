### Miles · [meetmiles.info](https://meetmiles.info)
*Your reps drive. Miles navigates.*

An AI tool for car dealership sales reps. Miles drafts the first text, the reply and the follow-up a dealership's best closer would send, and it runs alongside the store's CRM. It knows the dealer's lot, remembers every customer, and never stores a conversation.

- **Stack:** Chrome extension, Cloudflare Pages Functions plus a self-hosted Node backend on SQLite, and the Claude API (Sonnet and Haiku) with prompt caching
- **How I work on it:** I check every change against saved real-world cases before it ships, and run side-by-side model comparisons on quality, speed and cost per draft

### Tindral · [tindral.io](https://tindral.io)
*Market intelligence, forged.*

A crypto market dashboard that tracks phase and regime and posts a live calls board. It runs on a Linux server I administer: scheduled data pipelines, recording-only forward tests that check a strategy before it trades, and its own research tooling.
